# Student Council System

**Веб-приложение для организации и управления студенческими объединениями.**

##  О проекте

Student Council System — дипломный проект, направленный на создание информационной системы для взаимодействия со студенческими организациями и управления их деятельностью.

Проект разрабатывается с целью применения навыков программирования, работы с базами данных и создания пользовательских веб-интерфейсов.

## Основные возможности

- Авторизация пользователей.
- Просмотр студенческих организаций.
- Работа со страницами организаций.
- Управление информацией об организациях.
- Создание и отображение данных об организациях.

## Технологии

- Python
- FastAPI
- HTML
- CSS
- PosgreSQL

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/Arina2204/student-council-system.git
```

2. Перейти в директорию проекта:

```bash
cd student-council-system
```

3. Создать виртуальное окружение:

```bash
python -m venv .venv
```

4. Активировать окружение:

```bash
.venv\Scripts\activate
```

5. Установить зависимости (при наличии файла requirements.txt):

```bash
pip install -r requirements.txt
```

6. Запустить приложение:

```bash
python main.py
```
